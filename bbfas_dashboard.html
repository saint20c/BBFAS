● PART 1 · 진단 심화 이론 (메인) — 차시 1~10
01 BBFAS 6유형 체계 수립 핵심 이론
2축 교차 분류
1축 : 골격 재질 (기존 3유형)
2축 : 비례 분포 우세 부위
교차 → 6유형 도출
6유형 명칭
S-Ⅰ 선형 직선 / S-Ⅱ 균형 직선
W-U 상체 웨이브 / W-L 하체 웨이브
N-S 어깨주도 / N-H 골반주도
3유형 판별(What) → 6유형 설계(How)로 전환. 일본식 3유형의 설명력 한계를 한국인 체형 데이터 기반으로 극복
02 골격 우선순위 분석법 핵심 이론
분석 기준
부위별 골격 특성 충돌 시 처리법
상체 우세 vs 하체 우세 판별
골밀도·관절감 우선 순위
적용 시나리오
쇄골=웨이브, 손목=내추럴일 때
어깨=스트레이트, 무릎=웨이브일 때
→ 의사결정 프로세스 체계화
기본과정에는 없는 내용. '종합적으로 판단'이라는 말을 구체적인 의사결정 프로세스로 체계화
03 복합형 · 경계형 판정 프로토콜 핵심 이론
5변수 매트릭스
① 골밀도·뼈 프레임
② 상하체 비율 우세
③ 직업·드레스코드
④ 연령·체중 단계
⑤ 클라이언트 목표
판정 기준
70% 이상 → 단일 유형
50:50 → 복합형 기록
주 유형 + 보조 유형으로 표기
실습 케이스 5개
기본과정은 "두 특징이 함께 나타날 수 있다" 한 줄. 심화에서는 실제 케이스 5개로 판정 실습
04 얼굴형 + 골격 통합 분석 BBFAS 독창
통합 분석 원리
얼굴형 : 라운드·타원·각진·하트·역삼각
골격 유형과 얼굴형의 조화 매핑
충돌 시 우선 적용 기준
실전 적용

05 움직임으로 보는 골격 — Dynamic Frame Analysis (DFA) BBFAS 독창
정적 진단의 한계
사진·정지 자세는 실제 골격과 다를 수 있음
자세 보정·의상으로 가려지는 특성
긴장 시 근육이 골격을 덮음
DFA 3분 프로토콜
걸음걸이 관찰 (어깨·골반 이동)
